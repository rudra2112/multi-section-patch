# Review-Bound Apply Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bind every CLI apply to the exact reviewed dry-run plan and correct snapshot reuse, command-specific validation, and JSON error handling.

**Architecture:** Keep the existing `read` and `edit` commands. Add a deterministic SHA-256 over canonical planned files and resolved edits, require it through `--expect-plan` before writes, reuse one per-command snapshot cache, and annotate existing errors at command/item boundaries for JSON rendering.

**Tech Stack:** Go 1.23 language level, Go standard library only, existing shell artifact builder.

## Global Constraints

- Keep the feature limited to local bounded multi-file reads and edits.
- Require no Python, language runtime, network request, or telemetry for installed-skill use.
- Preserve Windows, macOS, and Linux support on x86-64 and ARM64.
- Preserve human-readable errors unless `--json` is requested.
- Do not add dependencies, commits, pushes, tags, releases, or staged files.
- Keep `docs/` internal and untracked.
